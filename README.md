# Retail Analytics Platform

An end-to-end retail data engineering project integrating a data pipeline, analytical data warehouse, interactive dashboard, and intelligent conversational interface.

## Project Objectives

- Ingest and process retail transaction data using Python.
- Design a MySQL data warehouse for analytical queries.
- Build reliable data transformation workflows using SQL and dbt.
- Implement data quality checks and pipeline orchestration.
- Develop an interactive dashboard for retail performance analysis.
- Build a controlled chatbot for natural-language data queries.

## Planned Technology Stack

- **Programming Language:** Python
- **Data Processing:** pandas
- **Database:** MySQL
- **Data Transformation:** dbt
- **Workflow Orchestration:** Apache Airflow
- **Containerization:** Docker
- **Dashboard:** Streamlit
- **Conversational AI:** LLM API
- **Version Control:** Git and GitHub

## Data Source

**Online Retail II** — UCI Machine Learning Repository

https://archive.ics.uci.edu/dataset/502/online+retail+ii

The dataset contains retail transactions that can be used to explore sales performance, customer purchasing behavior, product demand, and other business metrics.


# Retail Analytics Platform

An end-to-end retail data engineering project integrating a data
pipeline, analytical data warehouse, dashboard, and an intelligent
conversational interface.

## Project Objectives

- Ingest and transform retail transaction data.
- Design a data warehouse for business analytics.
- Implement data quality checks and pipeline orchestration.
- Build a dashboard for retail performance analysis.
- Develop a controlled chatbot for natural-language data queries.

## Planned Technology Stack

- Python
- SQL and PostgreSQL
- dbt
- Apache Airflow
- Docker
- Streamlit
- LLM API
